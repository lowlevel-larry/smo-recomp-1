# Code patches for Super Mario Odyssey 1.4.1 (recomp/patches.py; gen.py --patches recomp/patches-smo-v141.txt).

# word checked against the 1.4.1 modules. The mods' branch rewrites become rewrites of the instruction that feeds the
# branch, since a patched site cannot be a branch (patches.py). Every set is off by default: the game as shipped.
